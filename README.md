# Otra Escena

Consultorio personal para psicoanalistas: pacientes, sesiones, agenda, significantes y honorarios.

- Funciona como app instalable (PWA) en iPhone, Android, Mac y Windows, también sin conexión.
- Los datos **nunca salen del dispositivo**: se guardan cifrados (AES-256-GCM, clave derivada con PBKDF2) con una contraseña que solo conoce quien la usa.
- Backup cifrado exportable para pasar los datos a otro dispositivo.
